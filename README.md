# 董子豪，生日快乐 · 星光来信

专属生日祝福网页：星空蛋糕、许愿烟花、生日来信，适配手机和电脑。

## 发布到 GitHub Pages

打开本仓库 Settings → Pages，在 Build and deployment 中设置：

- Source：Deploy from a branch
- Branch：main
- Folder：/(root)

点击 Save 后等待 GitHub Pages 发布完成。发布地址：https://joechen-0510.github.io/sr/

## 页面文件

- `index.html`：生日祝福首页
- `style.css`：桌面和手机样式
- `app.js`：烟花与来信互动
- `birthday-cosmos.png`：星空蛋糕插画
- `favicon.svg`：网页图标

原有 `sr/` 文件夹保留。
